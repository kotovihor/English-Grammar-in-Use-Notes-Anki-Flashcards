# English Grammar in Use Notes & Anki Flashcards

This repository contains my structured notes, explanations, examples, exercises, and Anki flashcards based on **English Grammar in Use**.

The goal of this project is to organize English grammar topics in a clear and practical way, make regular revision easier, and improve long-term memorization with spaced repetition.

## Contents

- Grammar notes by topic
- Simple explanations
- Example sentences
- Exercises and practice materials
- Anki flashcards for revision

## Purpose

This repository is created for personal English learning, grammar review, and building a consistent study system using notes and flashcards.
